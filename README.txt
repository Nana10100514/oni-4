おにと、おさんぽ。妖怪追加版

このフォルダ全体を元のサイトの公開先へ配置してください。
HTTPSまたはlocalhostで開いてください。index.htmlの直接起動ではカメラ許可が使えない場合があります。
既存ページの見た目を維持する場合は、app.jsを差し替え、assetsフォルダとyokai.jsを追加し、app.jsのscriptタグ直前に <script src="yokai.js"></script> を追加してください。

妖怪は鬼より先に同じキャンバスへ描画するため、必ず鬼の後ろに出て、写真・動画にも写ります。
約15〜19秒ごとに組合せが変わり、9〜14秒かけて左の画面外から右の画面外へ通り抜けます。途中でフェードして消えません。同時に合計1〜3体。提灯は2〜3体、狸と狐はペアで並んで通ります。
河童画像は元から3体で1枚のため、1枠で3匹の河童が表示されます。
停止ボタンは鬼と妖怪の両方を止めます。大きさはzentaiの比率を目安に、画面内に収まる上限を設けています。
からかさは分割パーツを使った足の関節アニメーションです。追加イラストは不要です。
端末実機でのカメラ許可・録画・共有の動作確認は未実施です。
